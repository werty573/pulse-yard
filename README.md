# Pulse Yard: concept website

A single-page site for **Pulse Yard**, a fictional strength and conditioning gym in San Fernando.

Concept build by **Portside Digital**: websites that work. Pulse Yard is not a real business.

**Look:** Big Shoulders Display + Archivo + Space Mono, concrete grey with safety orange.

**Scroll animation** (GSAP + ScrollTrigger, switched off for people who prefer reduced motion):
- Giant hero lines slide past each other
- Counters that roll with the scroll
- Weekly class schedule with day tabs
- Photos thrown onto a pile while the section is pinned
- Free-week sign-up form

Forms validate and show a success state, but don't send anywhere. On a client build they'd go to the owner's WhatsApp.

Photos: [Unsplash](https://unsplash.com) (Unsplash License).
